# Echo Music Android Release APK

Official Android release package for **Echo Music** (Version 2.0.0, Build 200).

---

## 📦 Release Package
- **File Name**: `EchoMusic-v2.0.apk`
- **File Size**: ~34.8 MB
- **Target OS**: Android 5.0 (API 21) up to Android 15 (API 35)
- **Signature Schemes**: Verified with v1 (JAR), v2 (APK Signature Scheme), and v3

---

## 🚀 How to Publish to GitHub Releases
1. Go to your GitHub repository: `https://github.com/<your-username>/<repo-name>/releases`
2. Click **"Draft a new release"** (or create a new tag `v2.0.0`).
3. Set Release title: `Echo Music v2.0.0 Release`.
4. Drag and drop `apk/EchoMusic-v2.0.apk` into the **"Attach binaries by dropping them here or selecting them"** box.
5. Click **"Publish release"**.

---

## 📱 How to Install on Any Android Device
1. Transfer or download `EchoMusic-v2.0.apk` to your Android device (via browser, USB, or Google Drive).
2. Tap the downloaded `.apk` file in your **Downloads** or **Files** manager.
3. If prompted by Android, tap **Settings** and allow **"Install unknown apps"** for your browser / file manager.
4. Tap **Install** and then **Open** to enjoy ad-free music playback!
