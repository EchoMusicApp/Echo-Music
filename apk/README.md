# Echo Music Android APK

This folder contains the release APK packages for **Echo Music** Android app.

## Files
- **`v2.0.apk`** (34.8 MB) - Production release package (Version 2.0.0, Build 2).
- **`echo-music-v2.0.apk`** (34.8 MB) - Release package with full app name.

## Features Included in APK
- Full-length offline audio bundle with Hi-Res playback
- Android Foreground Audio Service (`EchoAudioService`)
- Lockscreen media broadcast receiver & notification controls
- Synced lyrics with smooth animations
- AI Music Assistant & smart playlist generation
- SoundID song identification engine
- Equalizer & Bass Boost DSP
- Release signed with v1 (JAR), v2, and v3 signature schemes
