## Overview

**Pattukal** is my customized Android music-app project, built from the open-source Echo Music codebase. This repository contains the Pattukal-branded version and its website/build workflows.

The goal is to give the app its own Pattukal identity and a polished, smooth listening interface while preserving the existing playback functionality.

> **Project status:** Features and availability depend on the current build. Check the latest release notes before installing or updating.

## Download

Get the latest available APK from the [Pattukal website](https://t902968.github.io/pattukal-listen/) or the [latest GitHub release](https://github.com/T902968/pattukal-listen/releases/tag/latest).

1. Download the APK to your Android device.
2. Open the downloaded file.
3. If Android asks, allow installation from that source, then continue installing.

Only install APKs you trust. Android may show a security warning for apps installed outside the Play Store.

## What I'm working on

- Pattukal app name and visual identity.
- A premium violet, cyan, and blue liquid-glass visual style.
- Smooth interface transitions while keeping performance in mind.
- Keeping existing music playback and player controls working.
- A website with download information and release notes.

## Build from source

This is an Android project using Gradle.

```bash
git clone https://github.com/T902968/pattukal-listen.git
cd pattukal-listen
```

Open the project in Android Studio, let Gradle sync, then build the appropriate variant available in the project. A local Android SDK installation is required.

For GitHub Actions builds, open the repository's **Actions** tab and check the latest Android build workflow for its status and artifacts.
